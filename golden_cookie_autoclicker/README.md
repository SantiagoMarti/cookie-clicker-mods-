# 🖱️ Golden Cookie AutoClicker

A lightweight automation script for *Cookie Clicker*. 

This mod continuously monitors the game's internal arrays to automatically click special entities the moment they spawn, ensuring you never miss a combo opportunity.

## ✨ Features
* **Golden & Wrath Cookies:** Instantly clicked upon spawning.
* **Seasonal Drops:** Automatically catches Reindeer during the Christmas season.
* **Low Overhead:** Uses a 500ms interval check to minimize CPU usage while guaranteeing a 100% catch rate.

## ⚙️ Mod Information
* **Version:** 1.0
* **Dependencies:** None
* **Steam Achievements:** Supported (`AllowSteamAchievs: true`)
